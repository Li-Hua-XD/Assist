# ASSIST 2025-2026 CCC to UC All Majors

This repository contains 2025-2026 ASSIST CCC-to-UC Major articulation agreement summary data.

- `assist_2025_2026_all_majors/json/`: one JSON file per CCC-to-UC pair
- `assist_2025_2026_all_majors/index.csv`: flat index for all 1089 pairs
- `assist_2025_2026_all_majors/summary.json`: run summary and counts
- `scripts/fetch_assist_all_majors.js`: reproducible collection script

Summary from the collected run: 121 CCC menu options x 9 UC campuses = 1089 JSON files; 1080 non-empty, 9 empty, 0 failed.
